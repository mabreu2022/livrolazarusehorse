## Glossário Técnico do Volume 1

**Boss CLI:** Gerenciador de dependências e pacotes moderno para Free Pascal 
e Delphi, automatizando a resolução de dependências via `boss.json`.

**Chain of Responsibility:** Padrão de projeto comportamental em que uma 
requisição passa por uma esteira de manipuladores (middlewares) sequenciais.

**Correlation-ID:** Identificador universal exclusivo atribuído a cada 
requisição HTTP na borda para rastreamento distribuído em logs.

**Cthreads:** Unidade obrigatória no Linux para registrar a biblioteca POSIX 
threads no runtime multithread do Free Pascal.

**fphttpserver:** Servidor HTTP multithread nativo da biblioteca `fcl-web` 
do Free Pascal.

**Horse:** Microframework web minimalista e ultrarrápido para Object Pascal.

**JWT (JSON Web Token):** Padrão aberto RFC 7519 para transmissão compacta 
e assinada de declarações (claims) entre partes.

**RFC 7807:** Padrão IETF para comunicação estruturada de erros em APIs 
HTTP através do Problem Details.
